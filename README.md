# Personal Finance Tracker

A comprehensive **Personal Finance Tracker** web app developed using Windows Forms in the .NET Framework. This application is designed to simplify personal finance management, offering a range of features to help users track and control their financial health effectively.

## 🚀 **Features**
### Main Forms
1. **Start Form**: The welcome screen with navigation to Login and Register options.  
2. **Login Form**: Secure access to your account with authentication.  
3. **Register Form**: Create a new account to start tracking your finances.  
4. **Dashboard**: An overview of financial stats and personalized insights.  
5. **Income Management**: Add, view, and track your sources of income.  
6. **Expense Management**: Categorize and monitor your expenses efficiently.  
7. **Reports**: Generate detailed charts and graphs for financial insights.  
8. **Forgot Password**: Recover access to your account securely.  
9. **About Us**: Learn about the team and the mission behind the app.  
10. **Need Help**: Access FAQs and contact support for troubleshooting.  
11. **Subscription**: Manage subscription plans and additional features.  
12. **Extra Features**: Explore premium tools like savings tips, alerts, and goal tracking.

### Highlights
- **User-Friendly Interface:** Clean and modern design for an intuitive experience.

## 🛠️ **Technologies Used**
- **Programming Language:** C#  
- **Framework:** .NET Framework  
- **Development Environment:** Visual Studio  
- **UI Development:** Windows Forms  

## 📄 **How to Use**
1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/personal-finance-tracker.git
   ```
2. Open the solution file (`FinanceTracker.sln`) in **Visual Studio**.
3. Build the solution and run the application to start exploring its features.

## 💡 **Inspiration**
The app takes inspiration from popular finance tools like **Xero**, **YNAB**, and **Quicken**, aiming to provide users with a feature-rich yet simple solution to manage their finances.

- **Cloud Backup**: Sync data across devices securely.
